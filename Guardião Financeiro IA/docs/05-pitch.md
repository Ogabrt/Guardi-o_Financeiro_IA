# Pitch do Projeto

## Nome do projeto
Guardião Financeiro IA

## Frase de abertura
O Guardião Financeiro IA é um assistente virtual financeiro que utiliza dados estruturados do cliente para responder perguntas sobre gastos, metas financeiras, histórico de atendimento e sugestões de produtos adequados ao perfil do investidor.

## Problema

Muitos clientes possuem acesso a informações financeiras, mas têm dificuldade para transformar esses dados em decisões práticas. Mesmo quando há transações, metas e produtos disponíveis, essas informações costumam estar dispersas, o que dificulta o acompanhamento financeiro e a tomada de decisão.

## Solução

Para resolver esse problema, foi desenvolvido o Guardião Financeiro IA, um agente financeiro educacional capaz de interpretar dados simulados do cliente e responder de forma clara, objetiva e personalizada.

O agente utiliza uma base de conhecimento composta por:
- transações financeiras;
- histórico de atendimento;
- perfil do investidor;
- catálogo de produtos financeiros.

Com isso, ele consegue responder perguntas como:
- qual é o saldo do cliente;
- quanto foi gasto em determinada categoria;
- quanto falta para atingir uma meta;
- quais produtos são mais compatíveis com o perfil financeiro informado.

## Como funciona

O protótipo foi desenvolvido em Python com Streamlit, o que permitiu criar uma interface simples e funcional para demonstração.

Na aplicação, o usuário consegue:
- visualizar o perfil do cliente;
- consultar métricas financeiras;
- interagir com o agente por meio de perguntas;
- usar perguntas rápidas na lateral;
- receber respostas baseadas na base de conhecimento do projeto.

## Diferenciais

Os principais diferenciais do projeto são:

- personalização com base no perfil do cliente;
- uso de dados estruturados para fundamentar respostas;
- foco em segurança, evitando invenção de dados;
- recomendação compatível com objetivos e tolerância a risco;
- interface prática para uso e demonstração.
